# Joahan Morales — Portfolio

Portfolio personal de **Joahan Samuel Morales Piña** — Backend Developer & Project Manager, 4x Hackathon Winner.

Inspirado en [akshitvigg/portfolio](https://github.com/akshitvigg/portfolio).

## Stack

- Next.js 15 + React 19 + TypeScript
- TailwindCSS + NextUI
- Framer Motion floating dock
- GitHub Calendar + Icon Cloud
- Bilingüe EN/ES + dark/light mode

## Desarrollo

```bash
npm install
npm run dev
```

Abre http://localhost:3000

## NPX card

```bash
npx joahan-morales
```

## Deploy

Recomendado Vercel (repo `joahan-morales`):

```bash
npm run build
```

O conecta el repo a Vercel y deploy automático en cada push a `main`.
